# 钠与水反应的探究报告

## 目标

1. 用“浮、融、游、响、红”描述钠与水反应的关键现象，并把每个现象与密度、熔点、放热、气体生成或溶液碱性联系起来。
2. 正确书写并配平钠与水反应的化学方程式，说明 Na、H₂O 在反应中的电子转移关系。
3. 学会用“现象—证据—解释—结论”的结构组织探究报告，区分直接观察与依据资料作出的推断。
4. 认识钠与水反应的危险性，能提出符合实验室规范的安全措施。

## 要求

围绕问题“钠为什么会浮、融、游、响，溶液为什么会变红？”完成一份探究报告。报告建议 800—1200 字，或排版为 2—3 页，至少包含以下内容：

### 1. 研究问题与假设

用自己的话写出研究问题，并提出至少两条可检验的假设。例如：钠的密度小于水，所以可能先浮在水面；反应放热，可能使钠达到熔点。

### 2. 现象记录表

制作一张表格，至少包含“现象、证据、解释”三列，完整记录“浮、融、游、响、红”五个现象。若没有实际操作条件，可以依据课堂演示、课件和课程资料完成，但要注明资料来源，不要把推断写成亲眼观察。

### 3. 化学方程式与反应本质

写出带状态符号和气体箭头的配平化学方程式：

`2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g)↑`

并用简短文字说明：钠失去电子形成 Na⁺，水中的氢得到电子生成 H₂；NaOH 使溶液呈碱性，酚酞因此呈红色或粉红色。

### 4. 安全分析

解释为什么实验室只使用小块、少量钠，并说明大块钠遇水可能带来的风险。至少提出三条安全措施，必须包含远离火源、佩戴防护用品或使用防护屏、由教师进行演示或指导中的具体要求。

### 5. 结论与资料来源

用一段话回答研究问题，概括五个现象与反应方程式之间的关系。列出使用过的课程课件、课程资料或其他参考来源；引用图片、动画或文字时注明出处。

> **安全边界**：本作业不要求学生自行购买、携带或在家中进行钠与水的实验。不得为了拍摄视频而重复危险操作，也不得使用大块钠进行演示。

## 提交标准

- 提交格式为 PDF 或 DOCX，文件名建议为 `班级_姓名_钠与水反应的探究报告`。
- 报告必须包含研究问题、假设、五个现象记录、化学方程式、反应本质、安全分析、结论和资料来源。
- 方程式配平正确，物态符号和气体箭头书写清楚；“红”要解释为碱性溶液使酚酞显红/粉红色。
- 现象与解释一一对应，能区分直接观察、资料证据和自己的推断。
- 文档排版清晰，图表和文字可读；引用他人材料时注明来源，不整段复制资料原文。
- 在截止时间前将最终文件提交到课程指定位置；如需修改，请重新提交完整版本。
